# ⚡ Consumo de Energia de Aparelhos

## 📌 Sobre o Projeto
Este projeto é um programa simples desenvolvido em **Python** para calcular o **consumo mensal de energia elétrica** de um aparelho doméstico.

O usuário informa:
- Nome do aparelho
- Potência em watts (W)
- Tempo médio de uso diário em horas

Com esses dados, o sistema calcula o **consumo estimado em kWh por mês**.

---

## 🎯 Objetivo
O objetivo do sistema é demonstrar, de forma simples, como calcular o consumo de energia elétrica de aparelhos utilizando **programação em Python**.

Esse tipo de cálculo pode ajudar usuários a entender melhor o impacto do uso de aparelhos elétricos na conta de energia.

---

## 🧮 Fórmula Utilizada

O cálculo do consumo mensal é feito utilizando a seguinte fórmula:

Onde:

- **potencia** = potência do aparelho em watts (W)
- **horasDia** = quantidade média de horas de uso por dia
- **30** = número médio de dias no mês
- **1000** = conversão de watts para quilowatts

O resultado é apresentado em **kWh/mês (quilowatt-hora por mês)**.
